JenkinsQueueStuck alert drill - live capture
===============================================
Mechanism: a throwaway branch (drill/jenkins-queue-stuck) and a
throwaway Jenkins job (drill-queue-stuck) whose Jenkinsfile requests
agent { label 'nonexistent-drill-label' } - no real Kubernetes cloud
pod template matches it, so the build queues forever without ever
provisioning a Pod. Both deleted right after this drill.
